\# Home Assistant Add-on: CPU Stress Test



A simple CPU stress test tool for Home Assistant to evaluate processor heating and determine maximum core temperatures.



Jednoduchá zátěžová zkouška pro testování zahřívání procesoru a zjištění maximální teploty v Home Assistantu.



\## Features / Vlastnosti

\- Configurable duration (default 300s) / Nastavitelná doba trvání (výchozí 300 s)

\- Safety mechanism against loop-boot overheat / Bezpečnostní pojistka proti smyčce po restartu

\- Simple integration via Service Calls (`hassio.addon\_start`)
